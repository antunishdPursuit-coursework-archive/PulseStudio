# Pulse Studio — crawling rules.
# TEAM-OWNED: these rules protect member privacy sitewide.
#
# Member-facing pages are public. Staff-facing pages are NOT: they show
# rosters, attendance, and cancellation-risk information, which the shared
# data contract says must never leave the studio.
#
# THE TRAP THIS FILE AVOIDS — worth reading before editing it:
# "Disallow" blocks CRAWLING, not indexing. A disallowed page can still be
# listed from links pointing at it, and worse: a crawler that is not allowed
# to fetch a page can never SEE that page's noindex tag. So disallowing a
# page that carries noindex actively prevents the noindex from working.
#
# READ THIS BEFORE TRUSTING THE LINE BELOW (corrected 2026-08-21):
# This site is a GitHub Pages PROJECT page. It is served under
# /PulseStudio/, which means the file a crawler actually reads is
# https://antunishdpursuit.github.io/robots.txt — the root of the USER
# site, which lives in a different repository entirely. THIS file is served
# at /PulseStudio/robots.txt, and no crawler ever asks for it.
#
# So on the current deploy this file protects nothing. It is kept, and its
# path corrected, because it becomes real the moment the studio is served
# from its own domain — and because deleting it would quietly remove the
# record of what the rule is meant to be. Two things had to be fixed for
# that day to work: the prefix below was missing (a bare
# /products/b-dashboard/ matches nothing under /PulseStudio/), and this
# comment claimed the line was the staff dashboard's only protection.
#
# It is not protection, and right now the dashboard has none: neither
# app/products/b-dashboard/index.html nor its staff-dashboard.html carries
# a robots meta tag. The re-engagement tool does
# (<meta name="robots" content="noindex, nofollow">) and is deliberately
# left crawlable so that tag gets read and honoured, which is the only
# guaranteed way to stay out of an index. The dashboard needs the same tag,
# in its owner's lane — see docs/REQUESTFOR-A-B-C.md.
#
# Neither of these is a security control. A staff page holding real member
# data belongs behind a sign-in, not behind a politeness request.

User-agent: *
