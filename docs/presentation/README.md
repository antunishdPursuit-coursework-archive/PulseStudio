# Presentation

Two files, read in order:

- **[PITCH.md](PITCH.md)** — the five-beat story (role, problem, value,
  solution, watch-it-happen), content pulled from the site's own
  `app/shared/storytold.html` rather than re-derived from memory.

  this session, what's still in flight. Ages fast — it says so at the top.

Lives in `docs/` rather than the repo root because it's process material a
teammate reads before a presentation and ships to nobody — the same test
the filing law in `CLAUDE.md` applies to everything else here.
